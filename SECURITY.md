# Security policy

Please report security vulnerabilities privately through GitHub Private Vulnerability
Reporting: open the [Security tab of `titan-engine/titan`](https://github.com/titan-engine/titan/security)
and choose **Report a vulnerability**. Do not open a public issue.

Titan is pre-1.0 and makes no stability guarantees, so fixes land on `main` only. Include
reproduction steps and the affected commit, and we will respond as soon as we can.
